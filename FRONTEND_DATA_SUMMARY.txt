=== FORMS & VALIDATION ===

CHECKOUT: 9 required fields (first_name, last_name, email, phone, address, city, state, postal_code, country)
NEWSLETTER: email (required), name (optional)
PRODUCT ADD: size (required), quantity (required, >=1), color (optional)

Email validation: /^[^\s@]+@[^\s@]+\.[^\s@]+$/

=== OFFLINE SUPPORT ===

- Request queueing for POST/PUT/DELETE
- Offline orders marked with offline flag, ID format 'local-{timestamp}'
- Offline subscriptions with pending status
- Product cache for 5 minutes
- Sync on 'online' event

=== KEY FEATURES ===

- API Response Caching: 5 minutes for GET requests
- Retry Logic: 3 attempts with exponential backoff
- Request Deduplication: Same promise for identical requests
- Currency: Nigerian Naira (₦) format en-NG
- Tax: 7.5%, Shipping: Free
- Sizes: XS, S, M, L, XL, XXL with color variants
- Status values: pending, processing, shipped, delivered, cancelled (orders), pending/verified/failed (payments)
