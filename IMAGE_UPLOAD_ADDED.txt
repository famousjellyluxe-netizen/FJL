HOW TO USE:

1. Open Admin Dashboard
   http://localhost:5173/admin/

2. Go to Products page

3. Click "+ Add Product"

4. Fill in product details

5. Upload Image OR Enter URL:

   Option A: Upload
   - Click file input under "Product Image"
   - Select image from computer
   - See preview appear

   Option B: URL
   - Paste image URL in "Image URL (Optional)"
   - Example: https://via.placeholder.com/300x400?text=Jersey

6. Click "Save Product"

7. Product appears in table with image

8. Go to Shop page
   http://localhost:5173/shop.html

9. See product with image displayed!
