KEY CODE SNIPPETS: Featured Products vs Shop Page
================================================================================

================================================================================
THE CRITICAL DIFFERENCE - pointer-events: auto
================================================================================

SHOP PAGE (shop.html, lines 272-275) - HAS THIS:
---
        .product-info-header button,
        .product-info-header .add-to-cart-success {
            pointer-events: auto;
        }

FEATURED PRODUCTS (index.html) - MISSING THIS RULE ENTIRELY

IMPACT: 
Without this rule, if any parent has pointer-events: none, the button
can't be clicked. The shop page explicitly forces pointer-events: auto
to override any parent restrictions.

================================================================================
SCRIPT LOADING - THE TIMING ISSUE
================================================================================

FEATURED PRODUCTS (index.html):
---
Line 499:  <script src="notifications.js"></script>
Line 500:  <script src="cart-manager.js"></script>
...
Line 1104: <script src="cart-drawer.js"></script>

Problem: cart-drawer.js loads AFTER the inline featured products script
         that attaches event listeners.

SHOP PAGE (shop.html):
---
Line 862: <script src="cart-manager.js"></script>
Line 863: <script src="cart-drawer.js"></script>
Line 864: <script src="notifications.js"></script>
...
[inline script runs - all dependencies loaded]

Advantage: All external scripts load BEFORE the inline script that
          attaches event listeners.

================================================================================
LINK CLICK PREVENTION
================================================================================

FEATURED PRODUCTS (index.html) - Only has stopPropagation():
---
grid.querySelectorAll('.cart-icon-btn').forEach(btn => {
    btn.addEventListener('click', (e) => {
        e.stopPropagation();  // <-- Only this
        // ... rest of handler
    });
});

SHOP PAGE (shop.html) - Has stopPropagation() PLUS preventDefault():
---
// Prevent link navigation when clicking on add button
grid.querySelectorAll('a').forEach(link => {
    const button = link.querySelector('button.cart-icon-btn');
    if (button) {
        link.addEventListener('click', (e) => {
            if (e.target.closest('button.cart-icon-btn') || 
                e.target.closest('[data-lucide]')) {
                e.preventDefault();  // <-- Additional protection
            }
        });
    }
});

grid.querySelectorAll('.cart-icon-btn').forEach(btn => {
    btn.addEventListener('click', (e) => {
        e.stopPropagation();
        // ... rest of handler
    });
});

Impact: Shop page has explicit parent-level prevention in addition
        to button-level stopPropagation().

EVENT LISTENER - IDENTICAL
================================================================================

Both use identical code (featured lines 858-875, shop lines 1075-1095):
---
grid.querySelectorAll('.cart-icon-btn').forEach(btn => {
    btn.addEventListener('click', (e) => {
        e.stopPropagation();
        const isOutOfStock = btn.getAttribute('data-out-of-stock') === 'true';
        if (isOutOfStock || btn.disabled) {
            if (notifications) {
                notifications.error('This product is out of stock');
            }
            return false;
        }
        const productId = btn.getAttribute('data-product-id');
        const productName = btn.getAttribute('data-product-name');
        const productPrice = parseInt(btn.getAttribute('data-product-price'));
        const imageUrl = btn.getAttribute('data-image-url');
        openProductModal(productId, productName, productPrice, imageUrl);
        return false;
    });
});

No issues here - the click handlers are identical.
