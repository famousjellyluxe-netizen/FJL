1. CRITICAL CSS DIFFERENCE - EXPLICIT pointer-events: auto RULE
===============================================================================

FEATURED PRODUCTS: MISSING THIS RULE

SHOP PAGE (shop.html, lines 272-275):
        .product-info-header button,
        .product-info-header .add-to-cart-success {
            pointer-events: auto;
        }

THIS IS THE KEY DIFFERENCE!

Impact: Without this rule, if ANY parent element has pointer-events: none,
the button becomes unclickable. Shop page explicitly overrides this.
Featured products CANNOT do this without the rule.

ROOT CAUSES OF CLICK ISSUES (Priority Order)
===============================================================================

CAUSE #1 (CRITICAL): Missing pointer-events: auto rule
  - Without it, parent pointer-events: none can block clicks
  - Shop page explicitly overrides this
  - Featured products cannot protect itself

CAUSE #2 (HIGH): Script loading order

  - May cause DOM/event handling conflicts
  - Shop page avoids this by loading all scripts first

CAUSE #3 (MEDIUM): No explicit link prevention
  - Only stopPropagation() may be insufficient
  - preventDefault() is more explicit and reliable
  - Shop page uses both approaches
